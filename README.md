# Pixiv 本地排序

Tampermonkey 用户脚本。当前版本：**3.0.3**。

## V3

V3 改为作品中心的数据模型：

- Pixiv 搜索只负责发现作品 ID。
- 详情接口负责写入作品自身数据。
- IndexedDB 只保存作品，不保存搜索上下文归属。
- 保存原始 Tag 与 Pixiv 提供的中文翻译。
- 本地支持多 Tag 组合、AI、R-18、最低收藏与多种排序。
- 不选择 Tag 时，可直接对整个本地数据库筛选和排序。
- 作品卡片上的 Tag 可直接加入筛选。
- Fetch 节流参数可调，并保留暂停、停止和实时延迟状态。

## 数据字段

主要保存：

`id`、标题、作者、收藏、点赞、浏览、AI、R-18、尺寸、页数、作品类型、发布时间、缩略图、原始 Tag、Tag 翻译和抓取时间。

## 采集行为

采集关键词和页码仅用于发现作品 ID。当前 Pixiv 页面的 URL 筛选参数不会成为数据库分区，也不会影响已入库作品的后续本地筛选。

详情请求使用 `/ajax/illust/{id}?lang=zh`。Tag 显示顺序固定为：简体中文 → 其他中文 → 英文 → 原 Tag，不再使用未指定语言的随机兜底。

## 本地筛选

当前支持：

- 多 Tag：AND
- AI：全部 / 排除 / 仅 AI
- R-18：全部 / 排除 / 仅 R-18
- 最低收藏数
- 收藏数、收藏率、点赞数、浏览量、发布时间排序

## 数据库版本

V3 不迁移 V1/V2 数据。IndexedDB 升级到 V3 时会重建作品库，以保持数据结构和代码简单。
